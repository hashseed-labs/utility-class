# 前后端加解密工具使用说明

> 返回文档目录：[README.md](./README.md)  
> 单工具速查：[AesUtil.md](./AesUtil.md) · [RsaUtil.md](./RsaUtil.md)

本文说明 `AesUtil`、`RsaUtil` 的用法，以及「前端请求加密 ↔ 后端解密处理 ↔ 后端响应加密 ↔ 前端解密」的完整对接方式。

## 1. 工具概览

| 工具类 | 作用 | 推荐场景 |
| --- | --- | --- |
| `AesUtil` | AES 对称加解密 | 加密请求体 / 响应体（大数据） |
| `RsaUtil` | RSA 非对称加解密 | 加密传输 AES 密钥（小数据） |

**推荐方案（混合加密）：**

1. 后端持有 RSA 私钥，前端持有 RSA 公钥  
2. 前端每次请求随机生成 AES 密钥  
3. 业务 JSON 用 AES 加密；AES 密钥用 RSA 公钥加密后一并传给后端  
4. 后端用 RSA 私钥解出 AES 密钥，再解密业务数据；响应同样用该 AES 密钥加密返回  

若前后端约定固定 AES 密钥（仅内网/演示），可只用 `AesUtil`，省去 RSA。

---

## 2. 密文约定（前后端必须一致）

### AES

- 算法：`AES/CBC/PKCS5Padding`
- 密钥：16 / 24 / 32 字节（AES-128 / 192 / 256）
- IV：每次加密随机 16 字节
- 输出：`Base64( IV[16] + 密文 )`

### RSA

- 算法：`RSA/ECB/PKCS1Padding`
- 密钥：建议 2048 位
- 输出：`Base64(密文)`
- 注意：RSA 适合加密短数据（如 AES 密钥），不要直接加密大 JSON

## 3. AesUtil 使用示例（Java）

```java
import com.utility.AesUtil;

public class AesDemo {

    public static void main(String[] args) {
        // 方式一：生成随机 Base64 密钥（推荐）
        String aesKey = AesUtil.generateKey(128); // 或 256

        // 方式二：使用约定好的 16/24/32 长度字符串密钥
        // String aesKey = "0123456789abcdef"; // 16 字节 = AES-128

        String plain = "{\"userId\":1001,\"amount\":99.5}";

        // 加密（前端请求体 / 后端响应体都用这一步）
        String cipherText = AesUtil.encrypt(plain, aesKey);
        System.out.println("密文: " + cipherText);

        // 解密
        String decrypted = AesUtil.decrypt(cipherText, aesKey);
        System.out.println("明文: " + decrypted);
    }
}
```

## 4. RsaUtil 使用示例（Java）

```java
import com.utility.RsaUtil;

public class RsaDemo {

    public static void main(String[] args) {
        // 生成密钥对：publicKey 给前端，privateKey 仅后端保存
        String[] keyPair = RsaUtil.generateKeyPair();
        String publicKey = keyPair[0];
        String privateKey = keyPair[1];

        // 给前端 JSEncrypt 时，转成 PEM 格式
        String publicKeyPem = RsaUtil.toPublicKeyPem(publicKey);
        System.out.println(publicKeyPem);

        String aesKey = "0123456789abcdef";

        // 前端：公钥加密 AES 密钥
        String encryptedKey = RsaUtil.encryptByPublicKey(aesKey, publicKey);

        // 后端：私钥解密 AES 密钥
        String decryptedKey = RsaUtil.decryptByPrivateKey(encryptedKey, privateKey);
        System.out.println(decryptedKey); // 0123456789abcdef
    }
}
```

## 5. 完整对接流程（推荐）

### 5.1 报文结构建议

前端请求：

```json
{
  "key": "RSA公钥加密后的AES密钥(Base64)",
  "data": "AES加密后的业务数据(Base64)"
}
```

后端响应：

```json
{
  "data": "AES加密后的业务数据(Base64)"
}
```

响应复用本次请求的 AES 密钥即可（前端本地还留着明文 AES 密钥）。

### 5.2 后端示例

```java
import com.utility.AesUtil;
import com.utility.RsaUtil;

public class ApiCryptoExample {

    // 仅后端保存
    private static final String RSA_PRIVATE_KEY = "....";

    /**
     * 处理加密请求，并返回加密响应
     */
    public String handleEncryptedRequest(String encryptedAesKey, String encryptedBody) {
        // 1. 解出本次 AES 密钥
        String aesKey = RsaUtil.decryptByPrivateKey(encryptedAesKey, RSA_PRIVATE_KEY);

        // 2. 解密请求业务数据
        String requestJson = AesUtil.decrypt(encryptedBody, aesKey);
        // TODO: 反序列化 requestJson，执行业务逻辑
        String responseJson = "{\"code\":0,\"msg\":\"ok\",\"data\":{\"orderId\":\"A100\"}}";

        // 3. 用同一 AES 密钥加密响应
        return AesUtil.encrypt(responseJson, aesKey);
    }
}
```

### 5.3 前端示例（CryptoJS）

依赖：

```bash
npm install crypto-js jsencrypt
```

```javascript
import CryptoJS from 'crypto-js'
import JSEncrypt from 'jsencrypt'

const RSA_PUBLIC_KEY = '-----BEGIN PUBLIC KEY-----\n....\n-----END PUBLIC KEY-----'

/**
 * AES 加密：输出 Base64(IV + ciphertext)，与 Java AesUtil 一致
 */
function aesEncrypt(plainText, keyUtf8) {
  const key = CryptoJS.enc.Utf8.parse(keyUtf8)
  const iv = CryptoJS.lib.WordArray.random(16)
  const encrypted = CryptoJS.AES.encrypt(plainText, key, {
    iv,
    mode: CryptoJS.mode.CBC,
    padding: CryptoJS.pad.Pkcs7
  })
  // IV + ciphertext 再整体 Base64
  const combined = iv.concat(encrypted.ciphertext)
  return CryptoJS.enc.Base64.stringify(combined)
}

/**
 * AES 解密：输入 Base64(IV + ciphertext)
 */
function aesDecrypt(cipherTextBase64, keyUtf8) {
  const key = CryptoJS.enc.Utf8.parse(keyUtf8)
  const raw = CryptoJS.enc.Base64.parse(cipherTextBase64)
  const iv = CryptoJS.lib.WordArray.create(raw.words.slice(0, 4), 16)
  const ciphertext = CryptoJS.lib.WordArray.create(
    raw.words.slice(4),
    raw.sigBytes - 16
  )
  const decrypted = CryptoJS.AES.decrypt({ ciphertext }, key, {
    iv,
    mode: CryptoJS.mode.CBC,
    padding: CryptoJS.pad.Pkcs7
  })
  return decrypted.toString(CryptoJS.enc.Utf8)
}

/**
 * 发起加密请求
 */
/** 生成 16 字节 AES 密钥（UTF-8 字符串，与 Java 侧「原始字符串密钥」一致） */
function randomAesKey16() {
  const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'
  let key = ''
  const random = CryptoJS.lib.WordArray.random(16)
  const bytes = CryptoJS.enc.Latin1.stringify(random)
  for (let i = 0; i < 16; i++) {
    key += chars.charAt(bytes.charCodeAt(i) % chars.length)
  }
  return key
}

async function postEncrypted(url, bodyObj) {
  // 1. 本次请求的 AES 密钥（一请求一密）
  const aesKey = randomAesKey16()

  // 2. AES 加密业务 JSON
  const plain = JSON.stringify(bodyObj)
  const data = aesEncrypt(plain, aesKey)

  // 3. RSA 公钥加密 AES 密钥
  const jsencrypt = new JSEncrypt()
  jsencrypt.setPublicKey(RSA_PUBLIC_KEY)
  const key = jsencrypt.encrypt(aesKey)

  // 4. 发送
  const resp = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ key, data })
  })
  const result = await resp.json()

  // 5. 解密响应
  const responsePlain = aesDecrypt(result.data, aesKey)
  return JSON.parse(responsePlain)
}

// 调用示例
// postEncrypted('/api/order/create', { userId: 1001, amount: 99.5 })
```

> 注意：若 Java 侧 AES 密钥用的是 **Base64 随机密钥**（`AesUtil.generateKey()`），前端应按 **Base64 解码后的原始字节** 作为 CryptoJS Key，而不是把 Base64 字符串当 UTF-8 密钥。两端密钥编码方式必须统一。

## 6. 仅共享 AES 密钥的简化方案

适合内网、演示或已有安全通道的场景。

**后端：**

```java
private static final String AES_KEY = "0123456789abcdef"; // 16 字节

// 解密请求
String reqJson = AesUtil.decrypt(request.getData(), AES_KEY);

// 加密响应
String respCipher = AesUtil.encrypt(respJson, AES_KEY);
```

**前端：**

```javascript
const AES_KEY = '0123456789abcdef'
const data = aesEncrypt(JSON.stringify(body), AES_KEY)
// 请求只传 { data }
// 响应用同一密钥 aesDecrypt(result.data, AES_KEY)
```

## 7. 异常说明

| 场景 | 行为 |
| --- | --- |
| 明文 / 密文 / 密钥为空 | 抛出 `IllegalArgumentException` |
| 密钥长度不合法 | 抛出 `IllegalArgumentException` |
| 加解密失败（密钥错误、密文损坏等） | 抛出 `IllegalArgumentException` |

---

## 8. 安全建议

1. **RSA 私钥只放服务端**，不要写入前端代码或仓库明文。  
2. **AES 密钥尽量一请求一密**，通过 RSA 保护传输。  
3. 生产环境配合 **HTTPS**，加解密是对内容的额外保护，不能替代 TLS。  
4. 日志中不要打印明文密钥、完整私钥、完整业务明文。  
5. 若需国密算法（SM2/SM4），需另接 BouncyCastle 等库，本工具基于 JDK 标准 AES/RSA。
